LIMBUS BUILD TERMINAL v64r45 - 公開版
=================================================

■ このツールについて
  LIMBUS BUILD TERMINALは、Limbus TRPGで使うキャラクター情報を準備・確認し、CCFOLIA用JSONへ整えるための支援ツールです。
  TRPGのルールや裁定を決めるものではありません。ルールブックを確認しながら、セッションで参照する情報を整えてください。

■ 起動方法
  フォルダ構成を保ったまま、ローカルサーバー経由で開いてください。
  例: python3 -m http.server 8000 → http://localhost:8000/

  file:// で直接開くと、人格・E.G.Oデータの読み込みが失敗する場合があります。
  詳細は「使い方」画面と パッチノート.txt を参照してください。

■ v64r45 の主な内容
  ・人格の基本能力と斬撃・貫通・打撃耐性を、確認しやすい比較表示へ整理
  ・「別の人格を選ぶ」で人格一覧を開き、検索・絞り込みとカードの位置まで自動スクロール
  ・人格一覧を開く／畳む操作は、表示名が変わっても同じ大きさ・配置を維持
  ・設定画面でステータス一覧、初期値・上限の編集、CCFOLIA出力順を一つに統合
  ・主語を省略した「得る」「獲得する」を本人が得る効果として扱い、バリア、挑発値、保護、火傷、武装、属性別威力増加などを状態一覧とJSON出力へ統合
  ・「呼吸2とクイック1を得る」のように複数の状態を続けて得る本文も確認し、自己管理が必要な状態を取りこぼさない
  ・手動で作成・編集した人格でも、パッシブ、第2パッシブ、戦術スキル、ダイス、固有バフの本文を再確認
  ・敵・対象・味方への付与や単なる状態参照は自動追加しないため、不要な状態を混入させない
  ・対象の状態を条件にした変換は自分の派生状態として追加せず、PDFの改行で状態名が分断された場合も同じ扱いを維持
  ・DBで固有バフ・固有ステータスとして登録された名称は、本文に「得る」があっても既定ステータスへ追加しない
  ・バフ・デバフ・中立バフを問わず、DB固有値は設定一覧で「固有」として初期値・上限を編集可能に統一
  ・ワザリングハイツ・ワイルドハントのデュラハンを含む全登録値を、固有として保存・出力
  ・厳粛な哀悼の「生きた蝶・死んだ蝶」は弾丸を二種類へ分化するための固有処理として保持し、初期statusとCCFOLIA statusから除外
  ・分化後に数を管理する「生きた蝶」「死んだ蝶」は個別statusとして維持し、保存データ復元・固有バフ再読込でも分類を保持
  ・チャットパレットのE.G.Oコスト、パッシブ、覚醒・侵蝕の効果、ダイス実行ラベルからSAN表記を除外
  ・E.G.O本文内のSANは精神力と表示し、CCFOLIAで頻繁に操作するSANの検索候補をE.G.O本文が占有しないよう調整
  ・E.G.Oの資源コスト・効果・ダイスはパレットに残し、SANコストはE.G.O編集画面とメモで確認
  ・通常人格110件・特異人格20件を再監査し、自己管理状態の統合漏れ、固有値との重複、同じ状態の二重登録がないことを確認
  ・人格パッシブ、戦術スキル、ダイス、固有バフ本文で続いていた効果を句点と改行で整理し、編集欄・詳細表示で読み分けやすく改善
  ・固有バフの詳細表示も改行をそのまま表示し、181箇所の文境界を原資料と照合して補正
  ・第四銀工房太刀派フィクサーの錆びと、ジア家家主候補の赤撃で、欠けた状態名とダイス効果の所属を原資料どおりに修正
  ・マルチクラック事務所フィクサーとシー家私兵のパッシブ本文にあった分断を原資料と照合して修正
  ・条件文、引用、角括弧・丸括弧内の名称を、状態として自動追加しない
  ・別冊の通常人格・LCB人格・MAX人格を含む283件を、DB外の表記ゆれ・文脈の回帰確認に使用
  ・対象・敵・味方への付与を自分の状態に混入させず、未登録の値はカスタムステータスまたは固有バフを手動追加
  ・派生スキルは左上のオーダー欄でS4-2のように確認し、派生元・番号・条件の編集ブロックを撤去
  ・戦術スキルの固定d値上書き入力を撤去し、オーダー、種別、大罪、範囲を読みやすい情報帯へ整理
  ・装備中E.G.Oはスロットをクリックした時点で直接編集を開始
  ・E.G.O解析を通常・同化・影響の選択に応じた編集面へ整理
  ・同化スキルはS番号ごとのカードをそのまま編集でき、使用時などの効果をダイスより先に確認・入力
  ・同化スキルの入力内容は即時反映され、編集済みの分岐データを保持
  ・所持ライブラリ保存にアーカイブアイコンと引き継ぎ説明を追加
  ・人格編集のキーワード追加候補を、基本ルールPDFのバフ・デバフ掲載順へ整理
  ・E.G.O探索に、覚醒・侵蝕・パッシブ・同化スキルを横断するキーワード検索を追加
  ・メモとチャットパレットのカテゴリを、長押しドラッグまたは上下ボタンで確実に並べ替え
  ・390px幅を含むモバイル画面で、設定ステータス一覧の横あふれを防止
  ・長い編集画面、一覧、プレビューのスクロールバーを暗色トラックと金色つまみに統一
  ・HP・SANが人格と連動する表示を「現在値」へ統一
  ・使い方画面をLIMBUS BUILD TERMINAL 操作ガイドとして再構成し、「人格を装備する → 必要な情報を整える → 出力を確認して保存する」の順で案内
  ・使い方の導入、三段案内、折り畳み見出しの読み順・文字サイズ・余白を整理
  ・390px幅では、三段案内の番号・見出し・説明を同じ読み列に置き、説明を一行で確認可能に
  ・導入見出しの単語分断と、折り畳み見出しの項目数表示を取り除き、次に開く項目を確認しやすく調整

■ セーブデータ
  localStorage キー: lbt_v46_state
  既存の保存データを保持するため、保存キーは継続して使用しています。
  保存データの形式は schemaVersion 2 です。旧保存値を開いた場合も、現在装備中の人格に必要な自己管理状態を再確認します。
