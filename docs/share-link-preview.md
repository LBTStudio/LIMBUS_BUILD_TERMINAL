# 共有HTMLのDiscordリンクプレビュー

共有モーダルの「閲覧用URLを発行」は、生成済みのキャラクターシートHTMLを外部ホストへ公開する機能です。公開されたHTMLの`head`には、キャラクター名・人格・同期情報・主要ステータスから組み立てたタイトルと説明、およびLBT共通カード画像を埋め込みます。

DiscordなどのクローラーはJavaScriptを実行せず、取得したHTMLの`head`を参照してリンクカードを生成します。そのため、ローカルプレビューやダウンロードしたHTMLファイルではなく、**閲覧用URLを発行して得たHTTPS URL**を投稿してください。

> 発行URLの共有HTMLは誰でも閲覧できます。PL名、キャラクター名、設定や効果文など、公開して問題のない内容だけを含めてから投稿してください。

`og:image`はLBT GitHub Pages上の`assets/lbt-share-card.png`を参照します。キャラクター固有情報はタイトル・説明で表示し、画像はシートであることを識別する共通デザインとして維持します。

## Discordで反映が遅い場合

Discordが既に取得したURLのプレビューをキャッシュしている場合、カード更新まで時間がかかることがあります。内容を更新して再共有する際は、共有モーダルから新しい閲覧用URLを発行してください。

## 参考

[Open Graph Protocol](https://ogp.me/)では、`og:title`、`og:type`、`og:image`、`og:url`を基本メタデータとして定義しています。
