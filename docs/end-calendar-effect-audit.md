# 終末カレンダー効果監査

## 原典照合

対象はE.G.O「迫り来る日：終末カレンダー」（シンクレア、TETH）である。原典参照先は [Limbus Company Wiki: Impending Day Sinclair](https://limbuscompany.wiki.gg/wiki/Impending_Day_Sinclair) と [LCB攻略Wiki: E.G.O/シンクレア/迫り来る日](https://wikiwiki.jp/lcbwiki/E.G.O/%E3%82%B7%E3%83%B3%E3%82%AF%E3%83%AC%E3%82%A2/%E8%BF%AB%E3%82%8A%E6%9D%A5%E3%82%8B%E6%97%A5) を使用した。

DBは最終段階相当の値として照合する。覚醒スキルの条件付きダメージ量は+40%、敵討伐時は次のターンにパワー1を得て、全味方のHPを最大値の15%回復する。侵蝕スキルは敵味方識別不可で、対象HP25%未満へのダメージ量は+50%。敵討伐失敗時は次のターンに出血10とパワー3を得る。

現行DBの不整合は、覚醒・侵蝕の条件付き補正がともに+8、覚醒の回復が固定HP15、覚醒のパワーが2である点である。侵蝕側の+8も最終段階の+50%と一致しない。

## 監査方針

終末カレンダー固有の回帰テストに加え、E.G.O全件について本文とダイス効果の途中切断、見出し語の語中空白、句読点欠落、敵味方識別不可・次ターン・最大値割合などの定型表現を検査する。原典が確認できない候補は推測で変更せず、監査候補として記録する。
