# 終末カレンダー効果監査

## 正規基準

今回の正規資料は、添付された **新リンバスTRPG.pdf** とリポジトリ内の `data/db.json` のみとする。本編『Limbus Company』のWiki、ゲーム本編の性能表、外部攻略サイトはこのDBの修正根拠に使用しない。

PDFをテキスト化して確認したところ、終末カレンダーはPDF 251ページ相当の箇所に次の記述で掲載されている。

> 覚醒：対象のHPが25％未満ならダメージ量+8
>
> 28-1d15：敵討伐時、次のRにパワー2を得て全ての味方のHPを15回復
>
> 侵蝕：[敵味方識別不可] 対象のHPが25％未満ならダメージ量+8
>
> 28-1d15：敵討伐失敗時、次のRに出血10とパワー3を得る

`data/db.json` の終末カレンダー（TETH、No.16）と照合した結果、上記4項目はPDFと一致していた。前回の「+40」「+50」「最大値の15％」「パワー1」への変更は、本編ゲーム側の情報を誤って適用したものなので取り消した。

## 横断監査

DBのE.G.O名称100件をPDF本文と突き合わせ、名称がPDFに存在しないレコードは0件だった。E.G.O本文とダイス効果については、途中切断、語中空白、敵味方識別不可の崩れ、発動タイミング表記の破損、終端の助詞・活用途中切断を回帰検査する。PDFとDBの双方で確定できない推測修正は行わない。

## 再発防止

`tests/ego-effect-integrity.test.mjs` は、終末カレンダーのPDF記載値を固定し、E.G.O全件の明白な本文破損を検査する。今後のデータ修正では、必ず添付PDFまたはリポジトリDBを先に照合し、本編ゲームとの差異を勝手に補正しない。
