# v64r72 共有リンク発行・コピー導線の検証

検証日: 2026-08-17

共有モーダルを実画面で開き、閲覧用URLの発行項目に次の案内が表示されることを確認した。

> URL確定後は自動コピーを試み、同じURLを人手でもコピーできます。

共有URLの公開には外部ホストへの送信を伴うため、実データの外部送信は行わず、発行UIとローカルの自動テストで確認した。URL確定後は、コピー成否にかかわらずURL入力欄と「URLをコピー」操作を残す設計とした。

外部通信を行わないモック応答では、`navigator.clipboard.writeText`が発行URLを受け取り、自動コピー処理が実行されることを確認した。一方、実ホストからの発行成功後に残るURL欄・手動コピー操作については、互換ホストの実URLを確定してから追加検証が必要である。
