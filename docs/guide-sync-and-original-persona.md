# 同期化・創作人格チュートリアル

## 公式人格を卓用に調整する

### 1. 人格を装備する

人格図鑑で使いたい人格を選び、**「装備」**を押します。

### 2. 編集をはじめる

装備中人格の **「◈ 同期化して手動編集」** を押します。

名前、HP、SAN、耐性、パッシブ、スキル、固有バフが編集できるようになります。必要な場所だけ変更してください。

### 3. 同期状態を付ける

基本欄の **「同期化ランク」** で、`同期0`、`同期00`、`同期000` を選べます。

MAXなら、人格名の下にある **「同期MAX」** をオンにします。共有シートでは人格名に`[MAX]`が付きます。

### 4. 編集を終える

**「✓ 編集を終了（内容は保持）」** を押します。編集した内容はそのまま残ります。

もう一度直したいときは、再び **「◈ 同期化して手動編集」** を押してください。

## オリジナル人格を作る

### 1. 新しい人格を作る

人格図鑑の上部にある一覧バー（PERSONA LIST / 人格一覧）で **「＋ カスタム人格」**（**「テキスト流し込み反映」の左隣**）を押します。

> 一覧バーは、どれかの人格を装備しているときだけ表示されます。何も装備していないときは、先に人格を1つ装備してください。

名前を入力すると、創作人格がすぐに装備されます。

### 2. 中身を入力する

まず、人格名、HP、SAN、速度、耐性を入力します。次にパッシブとスキルを追加します。

固有バフがある場合は、**「UNIQUE BUFFS / 固有バフ・ステータス」** を開いて追加します。独自の検索用語を付けたい場合は、キーワード欄の **「手入力」** を使います。

### 3. 所持人格に保存する

入力が終わったら **「この人格を所持に保存」** を押します。

保存した人格は、人格図鑑の **「所持」** タブからいつでも呼び出せます。

### 4. 保存後に直す

保存済みの創作人格を装備し、**「◈ 同期化して手動編集」** を押します。

修正後は **「所持人格の保存内容を更新」** を押します。

## モバイル（スマホ幅）での操作

モバイルでは下部メニューに「人格」がありません。**「ビルド」**を開き、上部タブの **「人格」** を選びます（タブは横にスクロールできます）。

- 一覧バー（**PERSONA LIST / 人格一覧**）は、どれかの人格を装備しているときだけ表示されます。何も装備していないときは、表示範囲を **「全件（未所持も含む）」** にして人格を1つ選び、詳細の **「装備する」** を押します。
- **「＋ カスタム人格」** は **「テキスト流し込み反映」の左隣** です。狭い画面ではバーが2段になり、2つのボタンが等幅で並びます（高さ40pxでタップしやすい）。一覧を折りたたんでいてもボタンは表示されます。
- 押すと名前を聞くダイアログが出ます（初期値「創作人格」）。決定すると **CUSTOM / 創作** としてすぐ装備され、「カスタム人格『◯◯』を装備」と表示されます。
- プレビューは右端の縦タブ（**「▶ 展開」／「◀ 格納」**）で開閉できます。開いていると一覧バーが隠れるときは、タブで格納するか一覧が見える位置までスクロールします。
- プレビュー内の並べ替えは、**「⋮⋮」を長押ししてからドラッグ**します（短いスワイプはスクロールになります）。**「↑」「↓」** ボタンでも一段ずつ移動できます。
- 人格を探すときは、一覧内の検索欄（名前・パッシブ効果・キーワード）か、画面上部の検索（クイック検索）を使います。
- 保存は **「この人格を所持に保存」**、修正は **「◈ 同期化して手動編集」** → **「所持人格の保存内容を更新」** です。
- 共有は **「操作・保存」** → **「共有シートを開く」** → **「① Discord対応URLを発行」** の順です。

## 共有する

共有シートから **「① Discord対応URLを発行」** を押します。

公式人格、同期化した人格、創作人格のどれでも同じ手順です。創作スキル、固有バフ、独自アイテム、改行や記号も共有先でそのまま復元されます。
