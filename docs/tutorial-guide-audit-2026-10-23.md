# 使い方（チュートリアルガイド）監査

- 監査日: 2026-10-23
- 対象: アプリ内「使い方」ガイドの初歩チュートリアルと詳細ガイド
- 照合対象: js/App.js、js/PersonaCodex.js、js/OtherSections.js、js/SkillDeck.js、js/state.js、既存テスト
- 方法: 表示文言、実際のボタンラベル、操作ハンドラー、保存／復元処理、フィルター実装をソース上で照合
- 制約: 実ブラウザー・実機での表示と操作の観察、スクリーンショット比較は未実施。コード上の仕様整合性を監査した結果であり、視覚面の実機検証の代替ではない

## 結論

ガイドの基本構成（人格を装備 → 必要項目を確認 → プレビューを見て保存）は、初めて使う人に向いた順序です。人格カードを一度選択して詳細を表示し、同じカードをもう一度押して装備する操作、カスタム人格の作成・所持保存、クイック検索、プレビューの用途も概ね現行仕様と一致していました。

一方で、ボタン名の不一致、E.G.Oの簡易詳細と解析モードの区別、保存と読み込み時の責務、検索できるフィルター条件など、利用者が誤操作や誤解をしやすい箇所がありました。今回、画面上の実ラベルと現在のハンドラーに基づいて説明を修正し、回帰テストも拡張しました。

## 指摘と対応

| 優先度 | 観点 | 監査結果 | 修正内容 |
|---|---|---|---|
| 高 | 人格の手動編集 | ガイドにあった「手動編集を開始」は実ボタン名と一致しません。現行UIは「◈ 同期化して手動編集」、終了は「✓ 編集を終了（内容は保持）」です。また、編集モードとゲーム上の同期ランク／同期MAXは別の操作です。 | 実ボタン名を案内し、編集モードとゲーム上の同期設定を明確に分離しました。 |
| 高 | E.G.Oの詳細と編集 | 旧説明は装備済み枠を押すと詳細と解析が一度に開くように読めます。現行動作は、クリックで右側に簡易詳細を出し、本文・ダイスの確認・編集には明示的に「解析を開始」を押します。未解析E.G.Oは必要な自我の欠片が不足していると解析を開始できません。 | 簡易詳細 → 解析開始 → 解析終了（内容保持）の順で説明し、開始条件も追記しました。 |
| 高 | 作業状態の保存と復元 | 旧説明は「現在の作業状態を保存」時に保存範囲を選ぶように読めました。現行の保存操作は編集中ビルド全体をJSONファイルへ書き出し、範囲を選ぶのは読み込み時です。通常の編集内容はブラウザー内へ自動保存されます。 | 自動保存、作業状態JSONの書き出し、読み込み時の適用範囲を別々の操作として説明しました。 |
| 中 | クイック検索と一覧フィルター | 旧説明は人格・E.G.Oの双方で、大罪・耐性・所持・同期状態が共通条件であるように読めます。現行の絞り込み条件は一覧によって異なり、同期ランク／MAXは共通の一覧フィルターではありません。 | 人格側の大罪・所属・耐性・所持条件と、E.G.O側のランク・必要資源／除外資源・所持条件を分けて記載しました。 |
| 中 | ナビゲーションの場所 | 旧案内はPCの画面移動を「上部バー」としていましたが、主な画面移動はPCでは左側ナビゲーション、スマートフォンでは画面下部のタブです。 | デスクトップとスマートフォンのナビゲーション位置を正しく案内し、保存・復元は「操作・保存」からも開けることを追加しました。 |
| 中 | ステータスと出力先 | 旧説明は固有ステータスの数値が各出力先に同じ形で反映されると断定していました。固有バフ等では、ステータス側・パラメータ側・登録先なしなど、出力先を選べる設定があります。 | 出力先の指定も確認するよう説明を修正しました。 |
| 低 | 元に戻す・やり直す | ショートカットの説明は概ね正しいものの、入力欄にフォーカス中はCtrl+Zが文字編集の取り消しを優先し、アプリ状態のUndoを実行しない点が省略されていました。 | 入力欄の外でアプリ操作を戻すこと、入力中は文字の取り消しが優先されることを追記しました。 |
| 低 | 一覧の並べ替え | 旧文は全一覧に▲▼ボタンがあるようにも読めました。実際はドラッググリップが基本で、矢印／▲▼による代替操作の有無は一覧によって異なります。 | 「対応する一覧では」と範囲を限定しました。 |
| 低 | 所持ライブラリの保存 | 「ライブラリ保存」という短い表現だけでは、画面上の実ラベルと、作業状態の保存との違いが分かりにくい状態でした。 | 実ラベル「所持ライブラリを保存」と、別端末へ引き継ぐデータ範囲、狭幅時の導線を明示しました。 |

## 良かった点（維持）

- 初歩の3段階（装備・確認・プレビュー／保存）は読み進めやすく、詳細ガイドより前に置かれています。
- 人格カードを一度押すと詳細、同じカードをもう一度押すと装備する操作は、現行挙動と一致しています。
- 「＋ カスタム人格」から作成し、「この人格を所持に保存」または「所持人格の保存内容を更新」で登録・更新する説明は現行UIと一致しています。
- クイック検索、プレビュー、メモ／チャットパレット／CCFOLIA用JSONという主要用語は適切です。
- モバイル幅ではガイドカードが一列に積まれるため、狭い画面で順に読める設計です。

## 回帰確認

tests/help-tutorial.test.mjs を拡張し、現行の人格編集ボタン名、E.G.Oの解析開始／終了、保存と読み込みの責務、一覧ごとのフィルター条件、ショートカットの例外、ナビゲーション位置、モバイル時の一列表示を検査します。

## 残る確認

本監査では実ブラウザーや実機での操作確認を行っていません。マージ前にPCとスマートフォンで、人格の手動編集、E.G.Oの解析開始／終了、所持ライブラリの保存、作業状態JSONの読み込み範囲の選択を一巡し、ガイド文と画面表示が自然につながることを確認する必要があります。
