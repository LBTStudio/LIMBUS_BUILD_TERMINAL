# 使い方（チュートリアルガイド）監査

- 監査日: 2026-10-23
- 対象: アプリ内「使い方」ガイドの初歩チュートリアルと詳細ガイド
- 照合対象: js/App.js、js/PersonaCodex.js、js/OtherSections.js、js/SkillDeck.js、js/state.js、既存テスト
- 方法: 表示文言、実際のボタンラベル、操作ハンドラー、保存／復元処理、フィルター実装をソース上で照合
- 制約: 実ブラウザー・実機での表示と操作の観察、スクリーンショット比較は未実施。コード上の仕様整合性を監査した結果であり、視覚面の実機検証の代替ではない

## 結論

ガイドの基本構成（人格を装備 → 必要項目を確認 → プレビューを見て保存）は、初めて使う人に向いた順序です。人格カードを一度選択して詳細を表示し、同じカードをもう一度押して装備する操作、カスタム人格の作成・所持保存、クイック検索、プレビューの用途も概ね現行仕様と一致していました。

一方で、ボタン名の不一致、E.G.Oの簡易詳細と解析モードの区別、保存と読み込み時の責務、検索できるフィルター条件など、利用者が誤操作や誤解をしやすい箇所がありました。今回、画面上の実ラベルと現在のハンドラーに基づいて説明を修正し、回帰テストも拡張しました。

## 指摘と対応

## 良かった点（維持）

- 初歩の3段階（装備・確認・プレビュー／保存）は読み進めやすく、詳細ガイドより前に置かれています。
- 人格カードを一度押すと詳細、同じカードをもう一度押すと装備する操作は、現行挙動と一致しています。
- 「＋ カスタム人格」から作成し、「この人格を所持に保存」または「所持人格の保存内容を更新」で登録・更新する説明は現行UIと一致しています。
- クイック検索、プレビュー、メモ／チャットパレット／CCFOLIA用JSONという主要用語は適切です。
- モバイル幅ではガイドカードが一列に積まれるため、狭い画面で順に読める設計です。

本監査では実ブラウザーや実機での操作確認を行っていません。マージ前にPCとスマートフォンで、人格の手動編集、E.G.Oの解析開始／終了、所持ライブラリの保存、作業状態JSONの読み込み範囲の選択を一巡し、ガイド文と画面表示が自然につながることを確認する必要があります。

### 現時点での評価

ガイドは、基本装備、編集、出力、復元までの主要な導線を前版より正確に示すようになりました。特に、保存操作のデータ範囲、編集済み人格の保存確定、読み込み前のチェック解除について、誤解によるデータ損失リスクを低減する説明へ更新しています。

なお、コードベース上で読み込み仕様まで照合した結果、抽選ログは現在のカテゴリ読込では復元されないという実装上の制約が残っています。これを意図した仕様とみなす根拠はこの監査では確認できていないため、完全バックアップ／完全復元をうたう説明は避けます。必要なら別の変更として、抽選ログを安全に移行可能にするか、作業状態ファイルから除外するかを設計判断してください。
