# 人格キーワード検出・フィルタ監査（2026-10-23）

## 結論

タグは現在、`data/db.json` の `keywords` 配列を基準に付ける手動分類です。旧フィルタはキーワード配列の値しか判定せず、スキル本文に現れる単語を検出してタグを自動付与するものではありませんでした。一方で、候補UIは出現頻度とルールブックの並び順・22項目の上限に依存していたため、単独のタグや独自タグが表示されず、タグが登録されても絞り込めないケースがありました。

## 検出精度に関する所見

- `煙` が効果テキストに登場していた通常人格4件（No.18「笑う顔たち」、No.92「ヴィリーブ工房フィクサーA」、No.93「ヴィリーブ工房フィクサーB」、No.117「歯車の教団信者」）には、いずれも煙の獲得・付与・消費・数値参照といった戦術上の操作がありました。修正ではこの4件に明示的な `煙` タグを付与しました。
- 単純なキーワード文字列検索だけでは誤検出します。例えば、あるパッシブでは「火傷・出血・振動・破裂・沈潜のうちランダムに1種を付与」と列挙されますが、それだけで5タグをすべて付けるべきとは限りません。特殊な分類ルールや付与の文脈も見る必要があります。
- そのため、新しい監査ツールは「操作」「消費・獲得」「数値条件・ごとの参照」などの強い根拠を候補化するだけにとどめます。検出結果からDBを書き換える処理は入れていません。既存タグに強い本文根拠が見つからない場合も削除せず、確認対象として別枠に出します。
- このルールベース検出器の完全な適合率・再現率は、199人格すべての原典と効果を人手でラベル付けした正解データがないため断定していません。監査は全件の候補抽出を助けるもので、原典照合を置き換えるものではありません。

## フィルタ修正

- キーワード候補一覧を現在の一覧内での出現頻度・PDFキーワード配列長に依存させないよう変更し、1件だけのタグ、カスタムタグ、選択済みだが現在の一覧では0件のタグも操作可能にしました。
- 各キーワードに現在の対象一覧内での該当件数を表示します。
- 複数選択を既定の「いずれか一致（OR）」にし、「すべて一致（AND）」を明示的に選べる操作を追加しました。この方式は大罪・キーワードの各カテゴリ内に適用し、カテゴリ間は従来どおりANDです。
- 既に判定ロジックが存在した所属フィルタにUIを追加し、所属条件を画面から選択可能にしました。
- 人格カード上で3件を超えるタグは「+N」として表示し、残りのタグ名はツールチップから確認可能にしました。
- `煙` を固定キーワード候補へ追加し、編集時にも既存候補として選べるようにしました。

## 実行方法

`node tools/persona-keyword-audit.mjs` は件数と先頭候補を表示します。`node tools/persona-keyword-audit.mjs --json` は根拠フィールドと一致断片を含む全候補を出力します。

`node --test tests/persona-keyword-audit.test.mjs` は煙の陽性ケース、ランダム状態列挙の陰性ケース、監査結果、フィルタUIの回帰条件を検証します。
