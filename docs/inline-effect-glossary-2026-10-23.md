# インライン効果リファレンス（2026-10-23）

## 表示規則

- **共通用語を優先**：バフ・デバフ・中立バフ・蓄積要素・弾丸は `data/provenance/core.paragraphs.txt` に抽出された基本ルールの定義を使い、紙面ページを併記する。
- **人格固有の用語は所有人格で絞る**：`data/db.json` の `unique_buffs` とパッシブ名は、現在表示している人格だけを参照する。他人格に同名の行があっても混ぜない。
- **E.G.O固有の用語は所有E.G.Oで絞る**：E.G.O名と固有説明を対応させ、別E.G.Oの説明を表示しない。
- 同じ語が複数人格のDBに複製されていても、原典に共通定義がある場合は原典定義を正本にする（例：武装、あなたの盾、充電力場、狂信）。
- 効果本文に登場するだけの未知語を定義として登録しない。別人格の本文から推測して説明を補わない。
- **「関連効果の例」は表示しない**。ポップオーバーには定義・出典を短く表示し、画面を占有しない。
- テキストはReactの通常テキストとして描画し、HTML文字列として挿入しない。

## 操作

- PC：ホバー、クリック、キーボードフォーカスに対応。Escで閉じる。
- スマートフォン／タッチ：タップ／約480msの長押しに対応。
- ポップオーバーはビューポート内へ収め、本文だけをスクロールできる。

## 検証

`node --test tests/inline-effect-glossary.test.mjs` で、原典の出典ページ、人格固有・E.G.O固有のスコープ、未知語を誤定義しないこと、最長一致、PC／タッチ操作、HTMLを文字列として挿入しないことを検証する。
