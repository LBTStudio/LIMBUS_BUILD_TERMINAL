# インライン効果リファレンス（2026-10-23）

## 目的

人格パッシブ／スキル／ダイス、E.G.Oのパッシブ・覚醒／侵蝕・固有効果、サポートパッシブ、アイテム、カスタムスキルの効果文に現れる用語・固有名詞について、別画面へ移動せず本文の近くから詳細を確認できるようにする。

## 挙動

- PC：用語上にマウスを置くと短い遅延後にポップオーバーを表示。クリックでも開閉でき、キーボードフォーカスとEscによる閉じ操作をサポート。
- スマートフォン／タッチ：タップで開閉し、約480msの長押しでも表示。
- 表示位置はアンカー要素の位置とビューポートから決め、画面端で左右・上下に収める。ポップオーバー本文だけをスクロールできる。
- ポップオーバーは用語につき定義・出典を1件だけ表示し、「関連効果の例」の一覧や件数は表示しない。
- 表示コンテキストの人格／E.G.O／アイテム等の所有者に一致する固有定義を優先し、それ以外は基本ルール由来の汎用定義を優先する。
- ポップオーバーのテキストはReactの通常テキストとして描画し、HTML文字列として挿入しない。

## 参照データと誤説明の回避

1. 標準バフ・デバフ（例：出血、火傷、束縛、煙、バリア）は、リポジトリに収録された基本ルールPDF抽出コーパスの該当ページ（p.304〜312）をもとに、ルール上の説明とページを表示する。
2. 人格の固有バフは `data/db.json` の `unique_buffs`（名前・種別・初期値・最大値・説明）を参照する。
3. E.G.O固有効果は `unique_buff` の記述と、E.G.O名／ランクを出典として表示する。
4. サポートパッシブ、死亡後パッシブ、精神状態、通常／特殊強化、アイテムの効果は既存DBの登録済み説明を参照する。
5. 効果文の角括弧（例：`[百足の毒]`、`[弾倉変換]`）内の名称は明示的な参照語として索引化する。別の正式な定義が見つからない場合は、その名称を使っている本文と出典を表示する。「定義がない」ことを勝手な効果説明で埋めない。
6. 検索対象を表示時に文字列分割するだけで、原文やDBは書き換えない。入力フォームは対象外。

## 検証

`node --test tests/inline-effect-glossary.test.mjs` で、基本ルール用語の出典、人格固有／E.G.O固有の説明、角括弧付き参照語、最長一致、PC／タッチ操作設定、HTMLを文字列として挿入しないこと、複数画面への統合を確認する。


## 2026-10-23 追加修正：同名の人格固有用語と汎用用語の分離

- ポップオーバーのコンテキスト引数を使い、表示中の人格／E.G.O／サポート／アイテムの名前を検索に渡す。
- 現在の所有者に一致する固有定義がある場合は、その1件だけを表示する。
- 汎用バフ・デバフ用語は基本ルールPDFの該当ページを優先し、人格ごとの使用例を混在させない。
- 一致する定義が複数の所有者にあるのに参照元が不明な場合は例示一覧を出さず、複数定義があることだけを短く案内する。
- 「関連効果の例」一覧と件数表示を削除し、1用語につき説明・出典を最大1件にする。
- 汎用定義の回帰検証はPDF抽出コーパス `data/provenance/core.txt` のページ区切りと照合する。


## 用語辞書の出典カバレッジ追加

初回のポップオーバー監査で見つかった、p.304〜311の一般バフ／デバフ表にある用語のうち辞書未収録だった項目（大罪・属性・デバフ関連の威力／ダメージ補正、d値強化、挑発値、電圧、血餐、自己共振回路）を追加した。PDF抽出時にセルの見出しが空白や改行で分割される場合もあるため、出典テストではページ区切りと空白を正規化して用語を照合。


さらにp.312の一般用語表に収録された弾丸8種類と、生きた蝶／死んだ蝶の説明を追加した。キャラクター固有の同名定義が現在の表示コンテキストに一致すればそれを優先し、別の場所で使われた場合にはルールブックの定義へフォールバックする。
