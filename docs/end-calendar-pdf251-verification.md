# 終末カレンダー PDF251ページ照合メモ

添付PDFの251ページ画像で確認した終末カレンダー（TETH No.16）の全文は以下のとおり。

- E.G.Oパッシブ名称：生贄の儀式
- 発動条件：なし
- 効果：敵討伐時、使用したスキルの大罪資源を5得る
- 覚醒：打撃：憤怒／対象のHPが25%未満ならダメージ量+8／28-1d15：敵討伐時、次のRにパワー2を得て全ての味方のHPを15回復
- 侵蝕：打撃：憤怒／[敵味方識別不可]／対象のHPが25%未満ならダメージ量+8／28-1d15：敵討伐失敗時、次のRに出血10とパワー3を得る

PDF画像のこの全文と `data/db.json` の対象レコードは一致している。現在の確認課題は、DBのダイス効果がE.G.O詳細UI・JSON・共有HTMLの各出力で省略または別テキスト化されていないかである。

## 最終UI確認（V65r66）

V65r66のE.G.O検索で終末カレンダーを選択し、簡易詳細に以下が表示されることを確認した。覚醒は「打撃：憤怒」「対象のHPが25％未満ならダメージ量+8」「28-1d15：敵討伐時、次のRにパワー2を得て全ての味方のHPを15回復」。侵蝕は「打撃：憤怒」「[敵味方識別不可]」「対象のHPが25％未満ならダメージ量+8」「28-1d15：敵討伐失敗時、次のRに出血10とパワー3を得る」。PDF251ページの文面と一致した。

今回確認できた実表示側の差分は、従来の簡易詳細がダイス効果本文を省略していたこと、および属性と罪・ダイス値と効果の区切りがPDFの「：」ではなく「·」または無区切りだったことである。V65r66で修正した。
