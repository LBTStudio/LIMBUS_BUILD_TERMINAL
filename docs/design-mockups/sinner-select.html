状態見た目 / 操作
通常surface-1 地に line 枠。hover/focus で金枠＋2px 浮上＋影。
使用中金枠＋金7%の地塗り＋金地バッジ「✓ 使用中」。選択ボタンは出さない（押しても同じ）。
hover / focusカード操作（編集・削除）が右下にフェードイン。:focus-within なのでキーボードでも出る。
タッチhover が無いため操作を常時表示。
削除confirm 必須。最後の1件には削除ボタンを出さない。旧データのバックアップには影響しない。
キーボードTab 循環（フォーカストラップ）、Esc で閉じる、開いた直後は最初の要素へフォーカス。
退場140ms のフェードのみ（translate で大きく動かさない）。prefers-reduced-motion は即時。

入場演出は「低頻度の操作」として 180ms フェード＋scale(.96)→1、カードは100ms間隔で順入り（上限500ms）。 保存・切替などの日常操作にはアニメーションを重ねません。
