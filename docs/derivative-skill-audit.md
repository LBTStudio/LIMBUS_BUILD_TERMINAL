# 人格DB 派生スキル監査

監査日: 2026-08-17

## 監査対象

通常人格と特異人格を別々の母集団として走査し、名称の接尾変化、スキル本文の「変更」表記、既存の`derived_from`・`derived_index`・`derived_condition`、同一ランクの複数登録を照合した。

| 区分 | 派生候補を含む人格 | 明示済み派生 | 推定候補 | 同一ランクの複数登録 |
| --- | ---: | ---: | ---: | ---: |
| 通常人格 | 2 | 1 | 1 | 1 |
| 特異人格 | 3 | 1 | 6 | 2 |

## 東部親指カポIIII

公開スキル表では、通常の攻撃枠は **スキル1《二連斬-【爆】》、スキル2《三連撃-【爆】》、スキル3《快刀亂麻》** とされている。猛虎標弾を保有したときは、《快刀亂麻》が特殊スキル《超絶猛虎殺撃乱斬》へ変化する。二連斬・三連撃は別の基本スキル番号ではない。[1] [2]

したがって、現DB内の「二連斬 → 二連斬-【爆】」および「三連撃 → 三連撃-【爆】」は、別番号として並べるのではなく、同一番号の派生状態として表現する必要がある。なお、公式資料上で明確な基本→特殊変化として確認できるのは《快刀亂麻》→《超絶猛虎殺撃乱斬》である。[1] [2]

## 修正結果

本文中の明示的なスキル変更を全人格で再走査し、未登録・別番号登録だった4件を修正した。ワザリングハイツ・ワイルドハントとLCEE.G.O:紅炎殺は、監査時点で既に派生表記が整合していたため変更していない。

| 人格 | 派生先 | 修正後の表示 | 派生元 | 条件 |
| --- | --- | --- | --- | --- |
| ジャーマ工房フィクサー | レッドアックス | スキル3-2 | スキル3 | シャインスピア使用後 |
| 東部親指カポIIII | 二連斬-【爆】 | スキル1-2 | スキル1 | 自分の弾丸が猛虎標弾なら |
| 東部親指カポIIII | 三連撃-【爆】 | スキル3-2 | スキル3 | 自分の弾丸が猛虎標弾なら |
| 東部親指カポIIII | 超絶猛虎殺撃乱斬 | スキル6-2 | スキル6 | 自分の弾丸が猛虎標弾なら |

この監査により、本文中で参照される同一人格内の5件のスキル変更はすべて、派生先が`派生元ランク-2`、`derived_from`、`derived_index: 2`を持つことを自動テストで検証するようにした。

GitHub Pages v64r78の実行時DBでも、東部親指カポIIIIの《二連斬-【爆】》《三連撃-【爆】》《超絶猛虎殺撃乱斬》が、それぞれ`スキル1-2`、`スキル3-2`、`スキル6-2`として読み込まれることを確認した。

## 訂正：カポの連番再修正

上記のカポに関する公開確認は誤りだった。快刀亂麻をスキル6としていたため、派生先も存在しないスキル6-2になっていた。LBT内の正しい連番は以下のとおりである。

| スキル | 正しいLBT表記 |
| --- | --- |
| 二連斬 | スキル1 |
| 二連斬-【爆】 | スキル1-2 |
| 三連撃 | スキル2 |
| 三連撃-【爆】 | スキル2-2 |
| 爆砕斬 | スキル3 |
| 快刀亂麻 | スキル4 |
| 超絶猛虎殺撃乱斬 | スキル4-2 |

派生先の`derived_from`は、必ず同一人格に実在する基礎スキル番号でなければならないことを全人格で検証する回帰テストを追加した。
