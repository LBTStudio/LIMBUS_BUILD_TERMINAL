## 東部親指カポIIII

原典PDF（基本ルールブック P.229-230）では、スキル番号バッジはスロット単位で振られ、《二連斬》/《二連斬-【爆】》、《三連撃》/《三連撃-【爆】》、《快刀亂麻》/《超絶猛虎殺撃乱斬》がそれぞれ同じ番号のバッジを共有する。各ブロック本文には「自分の弾丸が猛虎標弾なら《二連斬-【爆】》に変更」等の明示的な変化条件が書かれている。

したがって、DB内の「二連斬 → 二連斬-【爆】」および「三連撃 → 三連撃-【爆】」は、別番号として並べるのではなく、同一番号の派生状態として表現する必要がある。なお、原典本文上で明確な基本→特殊変化として確認できるのは《快刀亂麻》→《超絶猛虎殺撃乱斬》である。

## 2026-10-03 改訂：原典・硝子窓と同じ1始まり採番への全面正常化

上記までの監査で採用していた「基礎はplain・派生は`N-2`始まり」という採番は、原典PDFの実際の運用と一致しない独自規則だった。原典を座標レベルで精査した結果、正式な採番は次のとおりである。

- 原典PDFでは1つのスキル番号（余白のバッジ数字）に複数のスキルブロックが割り当てられることがある（例：剣契頭目の「肉斬/骨断」、カピターノの「エクセキューション/夜の錐」）。
- 硝子窓を含む公式の番号体系では、それらのブロックを印刷順（上から）に `N-1`, `N-2`, … と割り振る（本文中の参照も `S4-1`/`S4-2`/`S0-2` と1始まり。夜明事務所フィクサーAの[戦闘感覚]、E.G.O「ティビア」が明文で使用）。
- 形態が1つのスロットはplainな `スキルN` のままである。

これに合わせ `data/db.json` 全人格の複数形態スロット（27人格・89件）を印刷順どおりに振り直した。代表的な修正：

| 人格 | 修正前 | 修正後 |
| --- | --- | --- |
| 夜の錐カピターノ | エクセキューション=スキル3-2 / 夜の錐=スキル4 | エクセキューション=スキル4-1 / 夜の錐=スキル4-2 |
| 剣契頭目 | 肉斬=スキル4 / 骨断=スキル4（番号重複） | 肉斬=スキル4-1 / 骨断=スキル4-2 |
| 夜明事務所フィクサーA | 烙印=スキル0-2 / 正午の解体=スキル0（基礎と派生が逆） | 烙印=スキル0-1（基礎） / 正午の解体=スキル0-2（派生） |
| 東部親指カポIIII | 二連斬=スキル1 / 快刀亂麻=スキル4 | 二連斬=スキル1-1 / 快刀亂麻=スキル4-1 |

さらに、抽出器の「等距離タイは直前の番号を採る」デフォルト由来のスロット誤帰属3件を、原典バッジの幾何配置で検証のうえ修正した。原典では複数形態スロットのバッジ digit は**対（基礎+派生）の印刷中心**に置かれるため、バッジ位置が対の中心と一致する組み合わせが正しい帰属である。

検証は `tests/derivative-skills.test.mjs` が担い、全人格について「複数形態スロットは1..Kの連番・派生の導出式一致・単一形態はplain」を機械的に保証する。
