# V65r46 E.G.O右列簡易詳細カード — 実画面検証記録

## 実装前の確認

V65r43では、装備済みE.G.Oを選ぶと効果全文の詳細が装備枠・一覧の直下へ挿入されていた。未選択時は一覧をPC全幅へ広げる改善が入っていた一方、選択後には一覧右側の作業領域を要約参照へ利用できていなかった。

## 実装後の確認

V65r46では、E.G.O選択後に名称、ランク、SAN、欠片、必要資源、パッシブ要約、覚醒・侵蝕の種別とダイス式、装備状態、装備解除、所持追加を含む簡易詳細カードを表示する。装備済みスロットの選択時も一覧を展開して簡易詳細を必ず表示する。

効果全文と直接編集は、簡易詳細カードの「詳細・直接編集」からのみ開く。したがって、高頻度の比較・装備確認では一覧と要点を同時参照でき、低頻度の全文確認・編集では従来の専用詳細面を維持する。

## 幅別の挙動

1280px級のPCでは、一覧と簡易詳細を二列に配置する。1119px以下では簡易詳細を一覧の後ろへ単列配置し、横オーバーフローを防ぐ。390px相当では閉じる・装備・解除・詳細操作を44px以上の高さで表示する。

390px相当の実機エミュレーションでは、E.G.O候補を選択した後に簡易詳細カードが表示され、幅366pxで収まることを確認した。文書全体の横オーバーフローは発生せず、表示された主要操作は44pxの高さを保った。確認キャプチャは`v65r46-ego-quick-detail-mobile.png`、実測値は`v65r46-ego-quick-detail-mobile.json`に保存している。
